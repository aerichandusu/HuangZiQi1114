## 1. 系统定位

一句话描述：`<为谁、在什么场景、解决什么问题，例如：面向求职者的职位画像探索系统，帮助其判断"哪些城市/行业/岗位值得投递">`

目标用户（可二选一或双形态设计）：

- **求职者**：需要知道目标岗位在哪些城市更集中、薪酬区间如何、学历与经验门槛有多高。
- **企业 / HR**：需要知道同类岗位的市场薪酬水平、人才竞争分布与自身招聘条件的相对位置。

## 2. 数据说明

数据字段来自招聘信息（JobId / JobName / Province / City / Education / Experience / Salary / CompanyType），其中 `Salary` 形如 `{8000 - 15000, 14薪}`，需要拆解为月薪上下限与年薪月数。

本题不要求使用真实数据，方案中的取值可为模拟数据。
