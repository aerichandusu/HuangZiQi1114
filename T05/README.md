## 二、AI 具体使用情况

### 1.1 GitHub 与 Markdown 基础

这部分我原本只有使用github的基础并且不多，在AI的指令下安装了git并把对应代码写进去，从而成功按照目录要求搭建了自己的仓库。

### 1.2 研究总结

这是 AI 帮我最多的一项，但也是我参与判断最多的一项。

**它做了三件事**：一是精读。五篇核心文献加起来59页（Anchorage 15页、VisTellAR 13页、微课框架 6页、TED Talks 14页、M²Lens 11页），还有几篇延伸文献，全部由它先读一遍再提炼。二是给出可复用的框架，让五篇的写法一致，我不用自己每次重新组织。三是向我解释文献中使用的专业术语以及名词。当然我都是先把摘要和每个标题自己看了之后才让AI帮我分析难以看懂的主干部分，确实我的专业能力有限，所以很多东西还是要借助AI才能看懂。


### 1.3 可视化系统设计

我的设计想法是有的，但是本人最近确实很忙碌（sorry），如果从0开始手搓矢量图的话我就会耗费大量的精力。所以我先让AI把需求拆成"用户要回答哪些问题 → 对应哪些视图 → 每个视图用什么方式呈现"，形成信息架构；再让AI把地图、雷达图、矩形树图、热力矩阵这些矢量图发给我，结合AI的意见我自己对这些视图进行编排；最后额外生成一份矢量 SVG，让我拖进 Figma 就能当主画板继续改。

后来我觉得现在的职业分析系统肯定是比我做得更好的，所以我在思考怎么让我的设计更有新意，我想到现在很多人都会通过自己的MBTI人格特点进行职业规划，加上我一直觉得要选择一份适合自己性格的职业，所以我提出想加"个性关键词分析"（拖关键词进行分析）和 MBTI 匹配排行，并让AI帮我把关键词库按七个维度组织起来（40个词），把"关键词到岗位"的匹配规则写清楚（命中强关联词 +2 分、反向词 −1 分，上限 98%），最后我还是想实现个性关键词分析，便让AI帮我做了交互界面。

### 1.4 前端方向的可视化设计实现（未做）

这道题对应的是"雷达图里嵌地平线图"的增强雷达图，属于前端方向。我本次选择的是设计方向，没有写代码实现（主要也是能力有限），只和 AI 讨论并记录了对题目的理解与设计思路（雷达图负责表达各维度的均值，地平线图负责表达每个维度内部的分布，两者通过把地平线图画进雷达图的扇形区域来组合）。当然我的能力是做不出实现的，不过AI能把"这个图到底想解决什么问题"讲清楚，让我至少能理解题目。

### 文档与收尾

最后把Word里的五篇综述转成Markdown时，它统一了标题层级、把我写错序号的章节理顺（原来有一节从"一"跳到"三"）、把两个Word表格转成Markdown表格，还补齐了参考文献列表。我原来那三条从论文里机翻过来的贡献描述（"……时的问题表征"这类不通顺的句子），也请它改成了通顺的中文。

## 三、使用感受与反思

**1、使用感受**

**首先就是害怕**，因为我真的觉得自己的智慧比不上AI了，在研读文献的时候就产生了一种强烈的想法：为什么我的能力只有这么一点？但这又是有时效性的任务，所以我要在短时间里面完成就必须借助这个工具。于是我就只能一遍又一遍与AI对话，希望它写出来的总结是我能看懂的并且在我初步浏览时与我大致的印象是相吻合的。

**接着就是认清我自己和AI的劣势与优势**，因为我本人是新传专业，不折不扣的文科，虽然我已经在学习这些工具的使用，但基础很差，必须借外力的帮助。当我把我自己的想法告诉AI并询问它我自己要怎么做时，我发现AI更像一个老师，很清晰地告诉我下一步要怎么走。之前我觉得作业完全用AI写就很可悲，现在我仍然是这么觉得，但我对于AI的定位似乎更清晰，也没那么害怕了。因为我从想法形成到框架搭建以及最后的视觉效果一步步去思考时，会发现我也有很多自己独特的思考，而这是AI替代不了的东西。就比如MBTI，这是我自己一直以来在职业探索上的关注点（当然我没有刻板印象），所以当我与AI交流之后，我强烈想要把性格分析变成一个权衡岗位适配度的工具。总的来说就是我有自己的想法和创意，但是执行力不太行；而AI有非常强的执行力，但是它的想法并不能完全符合我心中的预期。

**最后是学会怎么更好的运用AI扬长避短**，我觉得这是很现实的东西。虽然不会的东西就要亲自去学去尝试，但是考虑到以后工作的情况下，怎么去把工作效率提高以及在尽可能短的时间里去解决自己"盲区"中的问题也是一个很重要的问题。我还是秉持之前的想法，AI不能当成"佛脚"，哪里不会就全让AI去解决。但是在现有的评判标准之下，学会用AI解决不会的问题应该是性价比较高的选择之一了。完成这个作业时我就在思考怎么让AI去填补我的劣势，因为代码这些东西我想要在有限的时间里面学会真是太难了，所以我的做法就是在初始阶段也就是想法上多下一点功夫，考虑怎么把一个东西做的更完善更有亮点，再让AI把我的想法实现出来，达到一个扬长避短的效果。或许这可能是未来我踏入职场后的做法吧。

**2、反思**

**不能否认的是AI发展到现在真是越来越强大了，方方面面都给人们提供了极大的便利**，但我总在思考，人工智能最前面的字是"人"，虽然说是人类发明的，但这背后还是寄托着**AI可以作为人类工具而不是替代人类的希翼**。人类在思考，所以人类一直存续着并且生生不息。或许有人会说"AI思考比人类还全面"，这是不可否认的，不然我们也不需要这个技术去辅助我们。**但人类的思考和AI的思考总还是不一样的，这里面掺杂着我的人生经历和情感寄托，这样的深度我想是AI一辈子都达不到的。虽然在现有的评判体系下，每个人都不能独善其身，被硬性指标所控制使得人们必须借助AI工具更好地完成任务。但我不会停止思考，我还是想继续保持敏锐的观察和深度的思考**。这是我自身专业——新闻学教会我的，也是我与AI的对话中所意识到的。
