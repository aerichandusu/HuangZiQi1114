# 增强雷达图（Radar Chart + Horizon Chart）实现思路与说明

> 对应任务 1.4【前端方向必做】可视化设计实现
> 源码见 `src/`，可直接浏览的构建产物放在 `build/`

## 1. 题目理解

要求实现的"增强雷达图"要同时表达两件事：

1. **各维度的均值**——用普通雷达图的多边形轮廓表达；
2. **每个维度内全部数据点的分布**——用**地平线图（Horizon Chart）**嵌在该维度所占据的扇形区域内表达。

数据为模拟的 50 家企业招聘 5 个岗位的报名人数，5 个岗位各自是一个维度：Software Engineer、Product Manager、HR Specialist、Data Scientist、Marketing Coordinator。

## 2. 图表原理

- **Radar Chart（雷达图）**：把 N 个维度按等角度分布在圆周上，每个维度用一条从圆心出发的射线表示；数值映射为半径长度，逐维连线形成多边形。适合比较"整体形状"与"维度间强弱"。
- **Horizon Chart（地平线图）**：一种紧凑的分布 / 时序可视化。把数值轴按统一的基线切成若干带（band），每个带用不同色阶填充并**叠加**在同一水平位置上，负值部分向下折叠或反向着色，从而在很小的纵向空间里表达较大的数值范围与分布形状。
- **组合方式**：为每个维度分配一个扇形区域（约 360°/5 = 72°），在该扇形内建立局部坐标系，把该维度所有数据点的取值排序后按地平线图绘制，使"均值轮廓"与"分布密度"在同一个极坐标体系里被同时读到。

## 3. 技术选型

| 方面 | 选择 | 理由 |
| --- | --- | --- |
| 渲染方式 | `D3.js` + SVG（必要时内层地平线图用 Canvas） | 极坐标计算与 `clip-path` 扇形裁剪方便，元素可交互 |
| 工程组织 | `Vite`（或纯 HTML + ES Module） | 构建产物简单，`build/` 可直接双击打开浏览 |
| 样式 | 原生 CSS / SCSS | 无额外依赖，`.gitignore` 已忽略 `node_modules` |

> 若选择纯 HTML + CDN 方式实现，则把 `index.html` 及相关资源直接放入 `build/`，确保无需本地服务器即可浏览。

## 4. 数据与预处理

1. 读取 5 个岗位各自的报名人数序列（每维 50 个数据点）。
2. 对每个维度分别计算：
   - 均值（用于雷达轮廓）；
   - 分布所需的分位数 / 直方图分箱（用于地平线图的色带高度）；
   - 归一化参数（把原始值映射到 0..1 的绘图区间）。
3. 由于数据量较小、分布可能"看起来诡异"，需在 README 中说明这一前提，避免把可视化结论当作真实统计推断。

## 5. 实现步骤拆解

1. **建立极坐标骨架**：定义半径 `r`、维度数 `n`、起始角与角步长；绘制网格圆环、维度轴与维度标签。
2. **计算均值多边形**：把每维均值映射为半径，得到顶点并用 `path` 连线，加半透明填充。
3. **为每个维度生成扇形区域**：用 `d` 属性构造环形扇区路径（`M ... A ... L ... A ... Z`）。
4. **在扇形内建立局部坐标系**：通过 `<g>` 的 `transform`（旋转到该维度角平分线方向）+ `clipPath`（按扇区裁剪）把直角坐标的地平线图"贴"进扇形。
5. **绘制地平线图**：在该局部坐标系中把该维度所有数据点排序、分箱，按色带逐层叠加填充；负值按反向色带处理。
6. **交互**：悬停显示企业级明细、点击维度高亮、图例与色阶说明；必要时提供"显示原始散点"的开关用于验证。
7. **构建与验证**：`npm run build` 后把产物复制到 `build/`，本地打开 `build/index.html` 检查渲染结果。

## 6. 运行方式

```bash
# 安装依赖
npm install

# 本地开发
npm run dev

# 构建
npm run build
```

构建产物放在 `build/` 目录，可直接打开 `build/index.html` 浏览。
