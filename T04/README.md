# T04 · 可视化设计实现（增强雷达图）

说明：本题我未实现代码与构建产物（本次选择的是设计方向），由于本人代码和理解能力实在是有限，下面只记录我对题目的理解与设计思路。

## 一、题目要做什么

用给定的 50 家企业、5 个岗位报名人数数据，画一张"增强雷达图"。它要同时回答两件事：**每个维度的整体水平有多高**，以及**每个维度内部所有数据点是怎么分布的**。

## 二、要用到的两种基本图表

**雷达图（Radar Chart）**：把 N 个维度按等角度分布在圆周上，每个维度对应一条从圆心出发的射线，数值映射为半径的长度，逐维连线形成一个多边形。它擅长表达"整体形状"，也就是各维度之间的强弱关系。

**地平线图（Horizon Chart）**：一种很紧凑的分布图。它把数值范围按统一的基线切成若干条带，每条带用不同深浅的颜色填充，并叠置在同一个水平位置上；负值部分向下折叠或反向着色。这样在很小的纵向空间里就能表达出较大的数值范围和分布形状。

## 三、两者怎么组合成"增强雷达图"

给每个维度分配一个扇形区域（5 个维度大约各占 72°），在这个扇形里画一张属于该维度的地平线图，用它表达该维度全部数据点的分布；同时，雷达图的多边形轮廓仍然表示各维度的均值。

这样一来，"均值轮廓"和"分布密度"就出现在同一个极坐标体系里，读者既能看出哪个维度整体更强，也能看出该维度的数据是集中在某个区间还是散得很开。这也是题目里"同时展示多维数据中各维度的分布情况"的意思。

**为什么值得这么做**：普通雷达图只能画出均值，会把维度内部的波动完全遮掉——两个均值相同的维度，实际可能一个是"所有人都差不多"，另一个是"一半人很高、一半人很低"。把分布信息放进扇形区域，恰好补上了这块缺失。
